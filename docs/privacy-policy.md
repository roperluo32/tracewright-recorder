# Tracewright Recorder 隐私政策草稿

最后更新：2026-04-25

Tracewright Recorder 是一个本地浏览器流程录制插件，用于把用户主动操作的网页流程转换为 Playwright 测试代码。

## 数据处理

- 插件只在用户点击开始录制后记录当前标签页中的操作步骤。
- 录制历史默认保存在浏览器本地 storage 中。
- 插件不会把 DOM、截图、用户输入、录制步骤或生成代码上传到服务器。
- 密码字段、隐藏字段、疑似 token / secret / API key 字段会默认脱敏。
- 用户可以在设置页清除本地录制历史。

## 权限用途

- `activeTab`：用户主动开始录制后访问当前标签页。
- `scripting`：向当前标签页注入本地录制脚本。
- `storage`：保存设置和本地录制历史。
- `tabs`：读取当前标签页标题和 URL，用于生成录制会话信息。
- `downloads`：允许用户下载生成的 `.spec.ts` 文件。

## 不包含

- 不包含账号系统。
- 不包含云同步。
- 不包含远程测试执行。
- 不包含第三方分析 SDK。
